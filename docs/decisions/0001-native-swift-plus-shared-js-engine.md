# 0001: Native Swift app with a shared TypeScript filter engine

**Status:** accepted (2026-11-24)

## Context
Screen Time APIs (FamilyControls, ManagedSettings, DeviceActivity) and their extensions are iOS-native only. Android has no equivalent, and its blocking approach will be entirely different. The part that *can* be shared is the logic that filters platform web apps.

## Decision
- iOS: Swift 6 and SwiftUI, minimum iOS 17, with the project generated by XcodeGen so that no `.xcodeproj` gets committed.
- Filter engine: TypeScript, bundled to a single IIFE with esbuild, injected into WKWebView now and Android WebView later.
- Rules: declarative JSON packs, separate from engine code.
- No cross-platform UI framework (React Native or Flutter). It wouldn't remove the need to write native code for each OS, and it adds weight.

## Consequences
- Native shells are written twice (iOS, Android). The engine and rules are written once.
- Rule packs can be updated independently of app releases (see 0002).
